# Covo — website

Marketing landing + legal pages for the Covo iOS app, served via GitHub Pages at **appcovo.com**.

- `index.html` — landing page
- `privacy.html` — Privacy Policy (`/privacy`)
- `terms.html` — Terms of Use (`/terms`)
- `support.html` — Support / FAQ (`/support`)

Self-contained static HTML (images and fonts inlined). Custom domain via `CNAME`.
